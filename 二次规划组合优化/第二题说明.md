第二题说明：

***注意第二题的代码运行需要在第一题跑出结果后才行）***

1.先计算用因子计算所有股票的预期收益（线性模型）

```text
expected_return_i,T+1 = beta_hat_T * factor_rank_zscore_i,T
```

其中：

- `factor_rank_zscore`：第一题中未经过行业市值中性化的排序标准化因子。
- `realized_return`：第一题中已经计算好的未来真实收益，用于估计历史 beta。
- `realized_beta_t`：第 t 日截面回归得到的因子收益。
- `beta_hat_T`：用过去窗口期的 `realized_beta` 滚动平均得到的预测系数。
- `expected_return`：预测出来的第 T+1 期股票收益，即后续组合优化里的 `mu`。

模型逻辑：我这里除了简单的线形模型以外，为了保证beta值的平稳，这里用滚动平均代替了 `beta_t` 的预测值。***滚动平均的窗口大小为 60 天。***
具体方法如下：
每天做一组截面回归：

```text
realized_return_i,t = beta_t * factor_rank_zscore_i,t + error_i,t
```

然后对历史 `beta_t` 做滚动平均：

```text
beta_hat_T = mean(beta_{T-window-1}, ..., beta_{T-2})
```

由于 T 日因子对应 T+1 开盘买入、T+2 开盘卖出的收益，形成 T 日信号时，
T-1 标签收益尚未完整实现。代码使用 `shift(2)`，只使用截至 T-2 已知的标签，避免未来函数。

默认参数：

```text
factor_col   = factor_rank_zscore
window       = 60
min_periods  = 20
return_availability_lag = 2
```

最后会生成供组合优化读取的内部缓存：
```text
.cache/二次规划组合优化/expected_returns.parquet
```
- `expected_return`：模型预测收益，后续二次规划使用。

2.具体的回测流程

对每天的股票池，先用因子进行选股，选出最好的前100只股票（注意由于我的因子是取了负号，所以默认选择因子最大的100只股票）


每个交易日执行：

```text
1. 按 factor_rank_zscore 从高到低选出前 100 只股票
2. 用截至 T-2 已完整实现的过去 60 个收益标签估计这 100 只股票的协方差矩阵
3. 对协方差矩阵做 20% shrinkage，增强稳定性
4. 求解组合权重
5. 用真实 realized_return 计算当期组合收益
```


优化模型如下

目标：

```text
maximize    mu' w
```

约束：

```text
sum(w) = 1
w' Sigma w <= max_variance
0 <= w_i <= 0.03
industry_weight_j <= 0.20
```

其中：

- `mu` 是股票预期收益。
- `Sigma` 是候选股票协方差矩阵。
- `w` 是股票组合权重。

## 默认参数

```text
candidate_count      = 100
risk_window          = 60
min_history          = 20
max_variance         = 0.0004
max_weight           = 0.03
max_industry_weight  = 0.20
shrinkage            = 0.20
```
