# 程序输出说明

`output/` 只保存最终 PNG 图片：

```text
output/
├── 单因子回测/
│   ├── IC检验/
│   │   ├── cumulative_ic.png
│   │   └── cumulative_rank_ic.png
│   ├── 直接分层回测/
│   │   └── group_backtest_*.png
│   └── 行业中性分层回测/
│       └── group_backtest_*.png
└── 二次规划组合优化/
    └── portfolio_cumulative_return.png
```

程序运行需要的大型中间数据放在被 Git 忽略的 `.cache/`：

```text
.cache/
├── 单因子回测/processed_data.parquet
└── 二次规划组合优化/expected_returns.parquet
```

`.cache/` 不是最终成果目录，可以通过重新运行程序生成。
